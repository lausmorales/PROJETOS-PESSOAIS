# SGPD — Sistema de Gestão de Processos Digitais

## 📌 Sobre o projeto

O **SGPD (Sistema de Gestão de Processos Digitais)** é um projeto acadêmico desenvolvido com o objetivo de propor uma solução para organização, acompanhamento e gerenciamento de processos digitais.

O projeto busca centralizar informações, organizar o fluxo das atividades e facilitar o acompanhamento das diferentes etapas de um processo, proporcionando maior controle e eficiência na gestão das informações.

## 🎯 Objetivo do projeto

Desenvolver e estruturar uma solução digital capaz de:

- Organizar informações relacionadas aos processos;
- Facilitar o acompanhamento das etapas e atividades;
- Centralizar informações importantes;
- Representar de forma clara os fluxos do sistema;
- Melhorar a visualização e o controle dos processos;
- Aplicar conceitos de Engenharia de Software no desenvolvimento da solução.

## 🛠️ Tecnologias e ferramentas utilizadas

- **UML** — modelagem e representação das funcionalidades e estruturas do sistema;
- **BPMN** — representação e análise dos processos de negócio;
- **C4 Model** — representação da arquitetura do sistema;
- **Figma** — criação e prototipação das interfaces;
- **Git e GitHub** — versionamento e organização do projeto.

## 📐 Modelagem do sistema

O projeto contempla:

- Diagrama de Casos de Uso;
- Diagrama de Classes;
- Diagrama de Atividades;
- Diagrama de Sequência;
- Modelagem de processos com BPMN;
- Representação da arquitetura utilizando C4 Model;
- Protótipo das principais telas do sistema.

## 📚 O que foi aprendido

O desenvolvimento do SGPD proporcionou uma experiência prática na aplicação de conceitos de **Análise e Desenvolvimento de Sistemas**.

Entre os principais aprendizados estão:

- Levantamento e organização de requisitos;
- Análise de problemas e necessidades dos usuários;
- Modelagem de sistemas utilizando UML;
- Mapeamento de processos com BPMN;
- Compreensão de conceitos de arquitetura de software;
- Criação de protótipos e representação de interfaces;
- Organização e documentação de projetos;
- Utilização de Git e GitHub;
- Transformação de uma necessidade de negócio em uma solução tecnológica estruturada.

## 🚀 Próximos passos

Como evolução do projeto, podem ser implementadas novas funcionalidades, integração com banco de dados, autenticação de usuários, controle de permissões e desenvolvimento completo das interfaces e funcionalidades propostas na modelagem.
